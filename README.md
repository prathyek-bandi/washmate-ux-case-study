Excited to share my first UX design project — WashMate! 🧺📱 A mobile app concept designed to make finding, booking, and tracking laundry services easier for hostel, PG, and apartment residents.  Designed in Figma as part of my learning journey with the TuteDude UI/UX Design Course. 

WashMate — UX Case Study

WashMate is a mobile UX concept designed to help hostel, PG, and apartment residents find, book, schedule, and track nearby laundry services.

🎯 Problem

Finding reliable laundry and ironing services can be inconvenient for residents in hostels, PGs, and apartments.

💡 Solution

WashMate brings service discovery, provider comparison, booking, payment, tracking, communication, and reviews into one mobile experience.
